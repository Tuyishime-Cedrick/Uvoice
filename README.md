# Uvoice

Uvoice is a structured debate platform where users can create debates, post arguments (for/against), and vote transparently.

See: docs/vision.md

## 🎯 MVP (version1)
- Create debates
- View debate list + debate details
- Add arguments (FOR / AGAINST)
- Vote on arguments
